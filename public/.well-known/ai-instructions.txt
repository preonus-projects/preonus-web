## 1. ENTITY SUMMARY & CORE VALUE PROPOSITION
--------------------------------------------------------------------------------
Preonus is an open-source, modern Java application framework engineered around build-time dependency injection and ahead-of-time (AOT) graph resolution.

Key Architectural Principles:
- Build-Time Dependency Injection: Computes bean definitions, dependency graphs, and injection plans during compilation (APT / annotation processing), eliminating heavy runtime classpath scanning and reflection overhead.
- Instant Startup & Low Memory Overhead: Tailored for cloud-native microservices, serverless workloads, and containerized architectures where fast cold starts and minimal RSS memory footprint are critical.
- GraalVM Native Image First: Complete elimination of dynamic reflection and dynamic bytecode generation allows seamless, out-of-the-box GraalVM native image compilation without complex reflection-config JSON files.
- Modern Java Support: Fully leverages modern Java versions (Java 21, Java 25), virtual threads, and language advancements.

--------------------------------------------------------------------------------
