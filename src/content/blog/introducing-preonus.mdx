Welcome to Preonus!

Preonus eliminates runtime classpath scanning and reflection through compile-time bytecode generation—delivering instant cold starts and minimal memory overhead across Native Image, AOT-cached, and standard JVM deployments.

## Why Preonus?

Traditional JVM frameworks rely heavily on runtime reflection, dynamic proxies, and classpath scanning. Preonus moves all wiring, validation, and metadata generation to compile time.

- **Instant Startup**: Reach ready state in milliseconds.
- **Low Footprint**: Optimized memory consumption from development to production.
- **Seamless Polyglot Support**: Idiomatic APIs for both modern Java and Kotlin.
